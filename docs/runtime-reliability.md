## 实现范围

保留现有供应商注册表、纯 HTTP 查询和 DSH 官方槽位。改动集中在查询一致性、路由归属、持久化所有权与设置交互。

| 范围 | 最终行为 |
| --- | --- |
| 查询结果 | Anthropic 费用使用官方字符串金额结构；OpenCode 空响应返回无数据错误。 |
| 调度 | 同一配置版本的刷新合并；更换配置后取消旧请求并查询新版本；卸载时取消查询。状态读取使用独立快照。 |
| 请求时限 | 单个 HTTP 请求最长 20 秒，包含多端点与分页的整次查询最长 120 秒。 |
| 路由归属 | 自动探测保留全部已识别路由，流量筛选、在用状态与记账共用同一解析入口。 |
| 会话生命周期 | 非调用事件不更新时间及顺序；宿主 `api-session/removed` 事件回收已删除会话的索引。 |
| 自动扫描 | 手动、启动、周期及事件触发使用同一执行入口；运行期间的新变化合并为后续扫描。 |
| 设置 | 草稿初始化及补丁生成集中处理；非秘密字段保留原值，空秘密字段不覆盖；失败显示错误并保留草稿。 |
| 连接测试 | 使用当前供应商编辑草稿，经服务器校验后查询，不持久化测试内容。 |
| 弹层 | 详情与设置具有对话框语义，支持 Tab/Shift+Tab 循环、Escape 关闭及关闭后的焦点恢复。 |
| 工程验证 | 增加故障恢复、跨进程合并、路由一致性、设置失败和浏览器测试，以及 Windows/Linux CI 和打包检查。 |

## 存储设计

继续使用版本 1 小时桶文件。相同路径的进程内实例共享存储；跨进程写入先获取短写锁，读取最新文件，再把当前实例相对上次成功保存的增量合并进去。不会全量覆盖另一个写者的新增用量，也不会把公共历史基线重复相加。

没有新事件且保留期未变时，不执行空闲保存。写入成功才推进基线；失败保留内存增量并退避重试。退出冲刷最多等待短写锁两秒。读取损坏或版本不支持的文件时保留原文件并上报错误，修复后可重试；替换失败会清理本次临时文件。

正常运行仍为同步小文件写入，没有引入数据库。合并后复用已经修剪的快照，避免重复遍历。异常终止可能留下写入锁；为避免误删活跃写者的锁，不按文件年龄自动抢锁。恢复步骤在 README 中说明。

## 验证

- Node.js 24.19.0：`npm ci --ignore-scripts` 成功；生产依赖审计未报告已知漏洞。
- `npm test`：26 个顶层测试项全部通过，包含原有脚本内部的多组断言。
- `npm run test:browser`：两个 Chromium 测试通过，覆盖错误保存保留草稿、组织 ID 保留、键盘焦点和 390px 窄屏详情。
- `npm run test:pack`：32 个文件、约 97 KB 压缩包；入口、客户端和必需运行时模块检查通过。
- 所有 `lib/*.js` 语法检查、`git diff --check` 和 CI YAML 解析通过。
- 独立安装 DSH `0.1.2-rc.1`，分别使用源码链接和最终压缩包安装到新的 `DSH_HOME`。profile 清单及组合配置均包含插件，两个实例均成功启动。
- 在真实 DSH 浏览器界面观察到“用量”槽位、详情和设置；非法轮询间隔被拒绝且表单保留，修正后保存成功；最终压缩包的窄侧栏与 Escape 焦点恢复通过手动验收。

存储基准使用 13 个供应商、每小时一桶，各执行十次完整冲刷。默认七天数据约 59 KB，中位耗时 4.71 ms；九十天数据约 759 KB，中位耗时 32.32 ms，最大 36.05 ms。本次删除重复修剪前，同一增量合并流程的九十天中位耗时为 58.52 ms。该测量只代表本机合成负载，不能推导其他机器或真实会话的响应时间。

## 验证边界

供应商响应测试使用模拟数据，未访问真实计费账户。真实宿主验收使用 Windows 与隔离数据目录；Linux 验证由新增 CI 配置承担，尚未在远端运行。安装包的 React peer 提示未阻止 DSH 安装及界面运行；浏览器 React 由宿主提供。

本次未增加许可证文件。跨重启事件重放去重仍依赖宿主稳定事件标识；文件系统持续拒绝写入或异常退出时，尚未持久化的增量仍可能丢失。
